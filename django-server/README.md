# A Django Webserver

A basic template to jumpstart an django webserver.
| Tool | Description |
| - | - |
| UV | Package management |
| Ruff | Formatting and linting |
| DRF | Rest Framework |

```bash
mise trust
mise install
mise format # for formatting
mise start # for local instance
```
